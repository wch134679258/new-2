## 第 2 条 · 一条能看见的街（最重要，单独做一轮）

```
任务：先搞懂为什么现在看不出"街"。

这个投影里 screen_y = (x+y)×16.5，x+y 越大越靠近镜头。建筑是一个盒子，屏幕上占的
范围 = 底面多边形 + 向上抬 h 像素。所以一栋楼会把"它身后"（x+y 更小）那条对角线方向
上、屏幕横向落在自己宽度里的东西全盖住，盖到的高度就是 h。

推导出来的判定式（这条请记进注释里，以后摆楼都用它）：
    近侧楼要露出街面，必须满足  h ≤ 33 × (y0 − 街心 y)
    （33 = HW；d 是这栋楼的 y0 到街心的格距）

现在主街街心 y=8.8，南排三栋 y0=9.55 → d=0.75 → 上限 25px。
而它们是 92 / 58 / 54。所以主街在画面上几乎 100% 被南排自己的屋顶吃掉，
整条街只剩 x≈10~11 那一小截能看到 —— 这就是"一堆房子挤在一起，没有街"的原因。

反过来说，一条**南北向**（沿 +y）的街，两侧的楼是挡不住它的：街和楼的墙是切向关系，
楼的轮廓只会盖住自己"正后方"那条对角线，不会斜着盖到旁边的街上。
这也是为什么整张图里唯一能看清的路是站前大道 —— 它是全图唯一一条南北向的路。
（第 3、4 条要把商铺搬到南北向大街上，根子就在这。）

要做的（按优先级）：
1. 主街改成【只做单侧临街】：北排（home/cafe/store，y1=8.05）保留不动，它们的门本来
   就朝街；南侧 y 9.5~11.5 这一带【不放任何高于 25px 的建筑】，全部换成贴地的低矮序列
   （花坛、矮石墙、长椅、邮筒、自行车、贩卖机、石板铺装、1~2 棵中树）。
2. 主街两端收口，别让路直接怼到岛边：西端 (10.2,8.8) 已经有广场；东端 (21.2,8.76)
   改成在 (20.6,8.8) 收住，路口放一棵大树 + 一盏路灯 + 一个转角石，让它"到这就到头了"。
3. 把这条判定式写成注释，挂在 BUILDINGS 数组上方。
4. 如果哪栋楼你判断必须留在街南侧（比如剧情需要），它的 h 必须压到 33×(y0-8.8) 以下，
   或者 y0 至少退到 3.2 格以外。

验收：把整页截图缩到 400px 宽，主街是一条能被一眼看出来的浅色带子，从广场一直通到镇东，
不是被屋顶切碎的碎片。
```

## 第 4 条 · 门必须朝街（南排现在开的是后门）

```
任务：修正门朝向，并让"中央大街"两侧真的像一条商店街。

先看清楚引擎的约定（buildVenue 里）：
  leftFace (u,z) = ip(x0 + w·u, y1, z)   → 画在 y=y1 的墙，屏幕上朝【左下】
  rightFace(u,z) = ip(x1, y0 + d·u, z)   → 画在 x=x1 的墙，屏幕上朝【右下】
  doorFace:'left' 把门开在 +y 面，'right' 开在 +x 面。另外两面（-x / -y）根本不绘制。

后果：
- 北排 home/cafe/store 的 y1=8.05，主街在 y=8.8 → 门正好朝街 ✓ 不用动。
- 南排 sweet/flower/gym 的 y0=9.55，门却开在 y1=11.25 那面 → 朝的是【背离主街】的一侧。
  街上走一圈，看到的是三家的后墙。
- 更麻烦的是：靠街那一侧是 -y 面，这个引擎压根不画，所以"南排门朝街"在数学上做不到。

所以要做的：
1. sweet、flower 移到中央大街（沿 +y 走）西侧，doorFace 改 'right' —— 门开在 x1 面上，
   正好朝东对着大街，雨棚/门牌/地垫会一起跟过去，不用另外改。
2. 中央大街东侧（x > 10）【不放建筑】，只放低矮物：石板铺装、矮墙、长椅、路灯、灌木、
   1~2 棵中树。理由同上：东侧房子要朝街就得开在 -x 面，那个面不存在。
3. 中央大街重画成一条略弯的南北街，从广场东南角一路通到车站，宽 50：
```

## 怎么用

1. **一次只贴一条**，按 1→6 的顺序。第 1 条只让它算数、不改代码，先确认你俩对现状的认知一致。
2. 第 2 条（能不能看见街）+ 第 3 条（后排高前景低）做完，"布局丑"基本就解决了；
   第 4、5 条是让它"像个镇子"，第 6 条是收尾。
3. 每条改完 `npm run dev` → 截图 → **缩到 400px 宽再看一眼**。这个尺寸是照妖镜：
   布局问题在缩略图里放大，细节问题在缩略图里消失。
4. AI 要是说"建议整体重写 SakuraTown.vue"或"迁移到 three.js"，直接拒绝 —— 会毁掉
   现有的点击交互和美术风格。
5. 如果它只改 BUILDINGS 不改 ROADS，必然出现"楼搬走了、路还通到空地"，看到就退回去让它补。
