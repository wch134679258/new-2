# 樱花小镇 · 视觉优化提示词

> 结论先说：小镇看起来"简陋"，不是细节不够，是**四件事没做好**——
> 建筑等大等高没有主次、阴影不随高度变化（贴纸感）、地面信息密度太低、
> 缺少垂直层次和"有人住"的痕迹。下面 5 条提示词按这个优先级排的。

---

## 通用头（每次新开对话，先贴这一段）

```
项目：D:\new-2\ja5-main\aurora-vue-2（Vue 3 + Vite，「樱见 SAKURA NOTE」樱花小镇）
目标文件：src/components/SakuraTown.vue（3156 行）、src/components/iso/{iso,props,scenes}.js

技术约束，必须遵守：
1. 地图是手写 SVG 的 2:1 等距投影，不是 3D 引擎。禁止引入 three.js / pixi / d3 或任何新依赖，
   禁止用位图贴图代替矢量。只允许改 SVG path、CSS、现有 canvas 粒子层。
2. 坐标系：SakuraTown.vue 中 HW=33、HH=16.5、G=21（21×21 格），ip(x, y, z) 把格坐标转屏幕坐标，
   poly() 拼路径。所有新元素必须用 ip() 定位，不许写死绝对像素坐标。
3. 建筑由 BUILDINGS 数组 + buildVenue() 参数化生成。建筑 key（home/store/gym/gamehome/
   cafe/sweet/flower/school/station）是交互契约，点击后 emit navigate(key)，不要改 key、不要删建筑。
4. 只做我这一条要求的事。不要顺手重构、不要拆文件、不要改主色（樱粉 #f9749f / 天青 / 奶白）。
5. 改完必须能 npm run dev 跑起来且控制台无报错。分步改，每步告诉我改了哪些函数。
```

## 第 1 条 · 密度分层与主次（解决"空旷 + 鞋盒感"，收益最大）

```
任务：给小镇做密度分层。现在 9 栋建筑体量几乎一样（w 1.9~3.6、h 54~92）、彼此均匀散在 21×21
网格里，最大的一栋是学校 h=88，其余都在 54~68；从缩略图看就是 9 个同款紫顶盒子摆在草地上。

要做的：
1. 把 21×21 划成 3 个簇，簇内建筑贴邻（墙间距 0.25~0.45 格，之间留 1 格巷道），簇间留 2~4 格空地：
   - 商业街簇：home(书店)、store(便利店)、cafe(咖啡馆)、sweet(甜品屋)、flower(花店)
   - 生活簇：gamehome(家)、gym(健身房)、park(公园)
   - 公共簇：school(学校)、station(车站)
   调整 BUILDINGS 里的 x/y 即可，不要改 w/d/h 之外的东西。
2. 加一个地标：广场中心偏后（约 8.5, 8.5 往后 1.5 格）建「樱花钟楼」，
   塔身 3 段收分、总高 h=140、顶层钟面 + 四角小尖顶，明显高于学校 88。
   钟楼要有独立点击回调（emit navigate 传 'clock' 时先不做页面跳转，只播放一个钟声音效占位 + toast）。
3. 樱花树分三级（现在所有树 rx 一样，是"撒盐"观感的主因）：
   大树 rx 34~40，只放岛边缘和广场，3~4 棵；中树 rx 20~26；小树 rx 12~16。
4. 补建筑之间的连接：石板小径（宽 0.6 格）从每栋楼门口接到主路、矮围墙、后院小门、晾衣绳。

验收：截图缩到 400px 宽，一眼能分出「商业区最密、公共区最空、中间有个高塔」。
建筑总数不变，9 个原有建筑全部仍可点击进入。
```

## 第 2 条 · 统一光照（解决"贴纸感"）

```
任务：统一光照方向，消除贴纸感。

现状：buildVenue() 里的 shadow 是把建筑占地往 +0.6 格平移出来的平行四边形，跟建筑高度完全无关
（第 1447 行），渲染时再套 filter: blurSm + opacity .18。结果是矮楼和高楼的影子一样长，
所有物体像浮在地面上。

要做的：
1. 定死太阳方向：光从左后方（-x, -y）来，投影往右下（+x, +y）。
2. 重写投影：shadow(x0, y0, w, d, h) —— 取建筑顶部四个角 ip(x, y, h)，
   各自沿 (+0.55h, +0.28h) 平移到地面，与地面四角 ip(x, y, 0) 连成闭合的六边形/八边形投影。
   楼越高影子越长。去掉 blurSm，改成实心填充 #6b4b69、opacity .16。
3. 加接触阴影（AO）：每栋楼沿落地墙脚画一圈内缩 2px 的深色带，opacity .22，无模糊。这一步最出效果。
4. 把立面明暗拉开：wallR（受光面）在原色上提亮 6%，wallL（背光面）压暗 10%。
   现在两面亮度几乎一样，所以看不出体积。写个 lighten/ darken 工具函数统一处理，
   不要一个个手改 30 个色值。
5. 树冠用椭圆投影（树冠所在位置 ip(cx, cy) 向下偏 h*0.4）、路灯／长椅／喷泉补短投影。

验收：截图里所有影子朝同一方向；建筑与地面接缝处有明显暗线；遮掉颜色只看明暗也能看出进深。
```

## 第 3 条 · 地面材质（解决"没画完"）

```
任务：重做地面材质。现在地面已有 grassGrad 渐变、12 块 patches 明度斑块、26 处 tufts 草簇，
但这三样都太轻（斑块太小、草簇是均匀撒在空格上），整体还是一块糊色。

要做的：
1. 草地分 3 层，把 PATCH_SPECS 从 12 块扩到 18~22 块、半径 3~6 格（现在 0.8~1.6），
   opacity .03~.05，边缘用不规则多边形而不是椭圆；main 目的只有一个：让人看不出地面是平的。
2. 草簇改"聚集式"：TUFT_SPECS 现在 26 处均匀分布，改成只出现在树根、墙角、石缝、路缘、
   溪岸边，3~5 株一簇成片；草地中央的空白处一律不放。均匀撒 = 噪点，成簇 = 植被。
3. 道路加重：
   - 主路两侧加路缘石（宽 0.12 格，比路面亮 8%），让路"浮"在草上
   - 路面加石板分格线（每 0.8 格一条浅缝，opacity .1）
   - 路口加转角石、井盖、排水沟箅子
4. 广场地砖：改成同心方砖（从中心向外 3 圈，每圈换明度），中心加樱花纹样地雕。
5. 溪流：water 上补 3~5 条白色波纹线，岸边加卵石带（20~30 个大小不一的椭圆，两种灰），
   水深从浅到深做 2~3 个色阶；瀑布落点加溅射细线。

验收：截图缩到 400px 宽，地面仍看得出层次（不是一块糊色）；缩略图上能看清路是路、草是草。
```

## 第 4 条 · 垂直层次与生活痕迹（解决"没人住"）

```
任务：加垂直层次和"有人在住"的痕迹。

现状：全部建筑都是 1 层盒子 + 同一个紫灰平顶（ROOF_LIGHT #8272a6 / ROOF_DARK #61528b），
ROOF_KIT 只有烟囱/天窗/天线三种配件；门口除雨棚外基本是空的。

要做的：
1. 至少 2 栋楼改 2 层：home(书店) 加二层带小阳台 + 栏杆 + 晒着的被单；
   cafe 加二层阁楼 + 斜窗 + 屋脊天窗。二层墙色 = 一层浅 8%。
2. 屋顶差异化，ROOF_KIT 扩到：瓦片缝线、屋檐出挑（多一圈 3px）、雨水槽 + 落水管、
   屋顶水塔、屋顶晾衣架。至少让 9 栋楼有 5 种不同屋顶。
3. 加电线杆 3~4 根（立在路边），杆间用二次贝塞尔曲线连电线，下垂 4~6px，两根并行。
   这是日系小镇最省成本、最有效的生活感符号，优先级仅次于第 2 条的光影。
4. 加生活小物：门口伞架、自行车 3 辆（斜靠墙）、自动贩卖机旁的空罐回收箱、
   店门口立式菜单牌、墙上空调外机、晾衣绳和被单、二楼的盆栽。
5. 每栋楼门口加地垫 + 门牌（门牌用 SVG text，写店名首字即可，字号 7~9px）。

验收：截图里随便挑 3 栋楼，能靠屋顶／层数／门口布置认出是哪一家，不看标签也能猜个八九不离十。
```

## 第 5 条 · 昼夜与天气（加分项，做成开关，别自动循环）

```
任务：加昼夜与天气状态，默认关闭，不影响现有逻辑。

要做的：
1. SVG 最上层加一个 overlay <rect>（铺满 viewBox），fill 由 CSS 变量 --sky-tint 控制：
   白天 transparent、黄昏 rgba(255,180,140,.18)、夜晚 rgba(60,50,110,.42)，夜里加 mix-blend-mode: multiply。
2. 夜晚状态：所有窗玻璃叠一层暖黄 #ffe2a8（opacity .85）；路灯周围加 radialGradient 光晕
   （半径 40，opacity .35）；广场地面加一点暖色反射。
3. 天气粒子复用现有 canvas 粒子循环（就是画 petals 的那个 requestAnimationFrame）：
   加 rain（细线，向下 + 微斜）和 snow（小圆点，缓慢左右摆），用 prop 切换，别另开一个 canvas。
4. 时间靠一个按钮手动切换（白天/黄昏/夜晚三档），不要自动流逝 —— 60 秒一个循环会晕。

验收：切到夜晚，缩略图能明确看出"天黑了、窗亮了"；白天样式与改动前逐像素一致。
```

## 怎么用

1. **一次只贴一条**。这文件 3156 行，一次让它改 5 件事必然崩。
2. 贴的顺序就是编号顺序。第 1、2 条做完，"简陋"的感觉已经去七成，第 3 条收尾，第 4、5 条是锦上添花。
3. 每条改完 → `npm run dev` → 截图对比 → 不满意就让它改，别急着贴下一条。
4. 如果 AI 说"我要重写整个 SakuraTown.vue"或"建议迁移到 three.js"，直接拒绝，那会毁掉现有的点击交互和美术风格。

## 另一条线（视觉之外）

上面五条只解决"看着简陋"。如果还想解决"玩着简陋"，那是另一套东西：
NPC 走动 + 对话气泡、每栋楼里的小交互（已有一间室内引擎 `iso/` 可复用）、
随机事件（下雨天车站有猫、夜里咖啡馆亮灯才营业）、小镇好感度／收集图鉴。
想动这条线时再单独说，别和视觉优化混在一轮里做。
