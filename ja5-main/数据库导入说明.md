# 数据库导入说明

项目实际使用的数据库名来自：

`springBootTest/src/main/resources/application-dev.properties`

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/springboot_test?...
```

因此库名是：**`springboot_test`**。

## 四步导入

### 1. 新建数据库

`init-db.sql` 已包含 `CREATE DATABASE IF NOT EXISTS springboot_test`，执行它会自动创建数据库，字符集为 `utf8mb4`。

### 2. 建立数据表

执行全量建表脚本：

```powershell
cd D:\new-1\ja5-main\springBootTest
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" -uroot -p --default-character-set=utf8mb4 < .\init-db.sql
```

该脚本是幂等的，已有的表不会被删除或覆盖。

### 3. 导入权限字段

已有数据库升级时执行：

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" -uroot -p --default-character-set=utf8mb4 < .\migrate-permission.sql
```

执行内容：

- 新增 `user.permission` 字段，默认值为 `1`
- 新增 `idx_user_permission` 索引
- 所有用户先设为普通权限 `1`
- 最早创建的用户设为管理员 `0`（当前项目中是 `verify用户`）

指定其他管理员时执行：

```sql
USE springboot_test;
UPDATE `user` SET `permission` = 1;
UPDATE `user` SET `permission` = 0 WHERE `name` = '要设为管理员的昵称';
```

### 3.5 建立金币经济系统（书店 / 便利店 / 健身房 / 公园）

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" -uroot -p --default-character-set=utf8mb4 < .\migrate-economy.sql
```

执行内容（幂等）：

- `user` 增加 `money` / `energy` / `energy_max` / `energy_at` / `last_sleep_date`
- `article` 增加 `price`（0 = 免费试读本）
- 新建 `purchase`（已购书目）与 `coin_log`（金币流水）
- 按分类给已有书目定价：小说 36 / 设计 26 / 技术类 20，并把 id 1、5、16 设为免费试读本

> 全新初始化直接双击 `恢复数据.bat` 即可，脚本已经把这一步排在 `migrate-article-content.sql` 之后。

### 4. 存储并核对数据

查询用户权限：

```sql
USE springboot_test;
SELECT id, name, permission,
       CASE WHEN permission = 0 THEN '管理员' ELSE '默认用户' END AS permission_label
FROM `user`
ORDER BY permission, id;
```

权限规则：

- `permission = 1`：默认用户，注册用户固定为 `1`
- `permission = 0`：管理员，才能看到“后台管理系统”并调用后台登录接口

## 密码存储

- 禁止存储明文密码
- 注册与登录继续使用现有 **BCrypt** 哈希
- 数据库中的 `password` 字段存放 `$2a$...` 形式的 BCrypt 摘要
- 后台登录与普通登录共用同一套密码校验，不会返回或输出密码明文
